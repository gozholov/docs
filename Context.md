# Текущее состояние (10.06.2026)

Документ для старта нового чата. Читать вместе с `README.md`.

## Проект

Сайт туристического комплекса «Тундра Парк» (~20 км от Мурманска, по Серебрянской дороге в Териберку). Заменяет старый `tundrapark.ru`.

Стек: **Next.js + TypeScript + Tailwind CSS + nodemailer**.

## Запуск

```bash
cd "/Users/gozolov/Сайт2"
npm install
npm run dev
```

Сайт: `http://localhost:3000`

| Файл | Назначение |

## Главная страница — 7 блоков (сверху вниз)

1. **Hero** — заголовок, кнопки, заглушка под фото. В тексте: «ездовые собаки» (не «хаски»).
2. **Что вас ждет** — заголовок «Мы покажем вам север!», 9 карточек. В карточке название «Хаски» (описание про ездовых собак).
3. **Программы** — фильтр Зима/Лето, цены, кнопки «Забронировать» и «Подробнее». «Подробнее» ведет на отдельную страницу программы. Сезон по умолчанию: май–сентябрь = Лето, остальное = Зима.
4. **Схема парка** — заглушка. Источник: `docs/Схема.jpeg`.
5. **Отзывы** — 3 заглушки под скрины из соцсетей.
6. **Как добраться + Контакты** — «20 км от Мурманска по Серебрянской дороге», иконки VK/TG/WA/MAX/WeChat.
7. **Форма заявки** — отправка на `tundrapark@yandex.ru` через `/api/request`.

## Страницы программ

Сделаны отдельные страницы по адресу `/programs/[slug]`.

Список страниц:

| Программа | Адрес |
|-----------|-------|
| Этническая программа | `/programs/ethnic-program` |
| Сафари на собачьих упряжках | `/programs/dog-sledding-safari` |
| Экспедиция на Лисью гору | `/programs/fox-mountain-expedition` |
| Сафари на снегоходах | `/programs/snowmobile-safari` |
| Оленьи упряжки | `/programs/reindeer-sledding` |
| Хаски хайкинг | `/programs/husky-hiking` |
| Хайкинг | `/programs/hiking` |
| Посещение этнической деревни | `/programs/ethnic-village-visit` |

На страницах есть: верхний блок, место под фото, сезон, длительность, блок «Подходит для», что входит, как проходит, что взять, питание, при необходимости «Можно ли с детьми» и «Важно знать», кнопка «Забронировать».

Тексты страниц удобно править в `docs/program-pages/`. После правок нужно перенести изменения в `data/program-pages.ts`.

## Форма заявки

Поля: имя, способ связи (Телефон, Telegram, WhatsApp, Email, MAX, WeChat), контакт, программа, дата, гостей.

SMTP: `yandex.env.local` с `SMTP_PASSWORD=...`. Пароль приложения Яндекс Почты (Почта · IMAP, POP3, SMTP). В настройках Яндекс Почты должен быть включён доступ для почтовых программ.

## Стиль работы с агентом

- Работаем **поэтапно, блок за блоком**.
- Комментарии касаются только указанного блока.
- Не читать все `/docs` без запроса — экономия токенов.
- На старте нового чата читать `README.md` и `docs/context.md`.
- Для работы с текстами программ читать `docs/program-pages/` и при необходимости `docs/Programs.md`.
- См. `docs/AGENTS.md`.
