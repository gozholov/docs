# Разработка сайта “Тундра Парк”

Документ фиксирует, как сейчас устроен технический каркас сайта и как его запускать.

## Что создано

Создан первый каркас сайта на Next.js, TypeScript и Tailwind CSS.

Простыми словами: теперь в проекте есть не только документы, но и основа настоящего сайта, которую можно открыть в браузере.

## Главная страница

Главная страница находится в:

- `app/page.tsx`;
- `components/HomePage.tsx`;
- `data/home.ts`.

В первой версии главной есть:

- первый экран с заголовком “Эпицентр северных приключений”;
- блок “Что вас ждет в Тундра Парке”;
- карточки программ;
- переключатель `Зима` / `Лето`;
- маршрут, контакты и форма заявки.


## Запуск

Сначала на компьютере должны быть установлены Node.js и npm.

```bash
npm install
npm run dev
```

Адрес локального сайта:

```text
http://localhost:3000
```

## Проверка

```bash
npm run lint
npm run build
```
